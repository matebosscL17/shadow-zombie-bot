# 🛠️ Patch Notes 2026.11.18 – Admin menü

## 🎮 Játékmódok az admin menüben - ÚJ
* Az admin menüben (**M → Admin menü**) új pont: **5. Játékmódok indítása**.
* Innen indítható: **Raj mód**, **Többszörös fertőzés**, **Pestis mód**, **Sniper mód**, **Assassin mód** és **Armageddon**.
* Sniper és Assassin módnál kiválaszthatod, **ki legyen** a Sniper / Assassin.
* A módok **kör elején** indíthatók, mielőtt valaki zombi lesz.
* A **Többi admin parancs** a **6.**, a **Kitiltás** a **7.** pontra került.
* A **Tulaj** minden admin menü pontot használhat.
